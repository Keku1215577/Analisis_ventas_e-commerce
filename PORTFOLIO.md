# Análisis de Ventas E-commerce

## Resumen
Proyecto de análisis de datos orientado a transformar información de ventas de un e-commerce en indicadores y hallazgos útiles para la toma de decisiones.

## Enfoque
- Exploración y preparación de datos.
- Análisis de ventas y comportamiento comercial.
- Identificación de patrones y tendencias.
- Visualización de resultados.
- Comunicación de hallazgos de forma clara.

## Tecnologías
- Python
- Pandas
- Jupyter Notebook
- CSV
- Visualización de datos

## Perfil profesional
Este proyecto demuestra habilidades relevantes para posiciones de **Data Analyst**, especialmente en preparación de datos, análisis exploratorio, interpretación de resultados y comunicación de insights.
