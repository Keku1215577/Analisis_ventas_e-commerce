# Análisis de ventas E-commerce

Proyecto de análisis exploratorio y visualización de un e-commerce ficticio utilizando Python y Jupyter Notebook.

## Objetivo

Analizar pedidos, clientes y tráfico web para obtener indicadores, tendencias y segmentos útiles para la toma de decisiones.

## Preguntas de análisis

- Cuáles son los principales indicadores del negocio.
- Cómo evolucionan los ingresos durante el periodo.
- Qué categorías y canales presentan mayor desempeño.
- Cómo se distribuyen las ventas por región.
- Qué segmentos de clientes pueden identificarse mediante RFM.

## Proceso

1. Carga y preparación de datos.
2. Limpieza y transformación.
3. Cálculo de KPIs.
4. Análisis temporal.
5. Comparación por categoría, canal y región.
6. Segmentación RFM.
7. Visualización de resultados.

## Tecnologías

Python, Pandas, NumPy, Matplotlib, Seaborn y Jupyter Notebook.

## Evidencia

El notebook analisis_ventas_ecommerce.ipynb contiene el flujo de exploración, cálculo de métricas y visualizaciones.

## Perfil profesional

Proyecto relevante para Data Analyst y Business Intelligence, especialmente por su enfoque en preparación de datos, KPIs, segmentación y comunicación visual.

## Alcance

Los datos son ficticios y se utilizan como práctica técnica.
